Support

Bugs and feature requests

Use the public GitHub issue tracker to report a reproducible bug or suggest a feature.

Include what you expected, what happened, and the steps needed to reproduce the problem. Screenshots are useful when they do not expose personal information.

Keep private information private

GitHub issues are public. Never include passwords, access tokens, authentication cookies, private invitation links, personal email addresses, or other users' information.
